# Wingman AI - Quick Features Reference

## 🎯 What Wingman AI Does

**Wingman AI is an open AI assistant that:**
- ✅ Analyzes screenshots of problems, code, documents
- ✅ Provides instant AI-powered solutions and explanations
- ✅ Chats with you about anything on your screen
- ✅ Records and transcribes audio/voice input
- ✅ Transcribes meetings and lectures live (with participant consent)
- ✅ Supports both cloud (Gemini) and local (Ollama) AI

---

## ⌨️ Essential Keyboard Shortcuts

```
Ctrl + B          →  Show/Hide Window
Ctrl + H          →  Take Screenshot
Ctrl + Enter      →  Solve/Debug Problem
Ctrl + R          →  Start Over (Clear All)
Ctrl + Q          →  Quit App
Ctrl + Arrow Keys →  Move Window
```

**Note:** On Mac, use `Cmd` instead of `Ctrl`

---

## 🎨 Main Features

### 1. 📸 Screenshot Analysis
- Press `Ctrl + H` to capture screen
- AI automatically analyzes content
- Perfect for coding problems, errors, documents

### 2. 💬 AI Chat
- Click 💬 Chat button
- Ask questions, get answers
- Automatic screenshot analysis
- Maintains conversation context

### 3. 🎤 Voice Recording
- Click 🎤 Record Voice button
- Speak your question or input
- AI transcribes and analyzes
- Great for meetings and notes

### 4. 🤖 AI Models
- Click ⚙️ Models button
- Switch between Gemini (cloud) and Ollama (local)
- Gemini: Fast, accurate, requires API key
- Ollama: Private, offline, free

### 5. 🔍 Solution Generation
- Take screenshot of problem
- Press `Ctrl + Enter`
- Get solution with code and explanation
- View complexity analysis

### 6. 🐛 Debugging
- Generate solution first
- Take screenshots of errors/code
- Press `Ctrl + Enter` again
- Get fixed code and explanations

---

## 🚀 Quick Start Workflow

```
1. Take Screenshot (Ctrl + H)

   ↓
```

## 🔧 Settings & Configuration

### **Switch AI Provider**
1. Click ⚙️ Models
2. Choose Gemini or Ollama
3. Configure settings
4. Apply changes
5. Test connection

### **Gemini Setup**
- Requires API key
- Get from: https://makersuite.google.com/app/apikey
- Fast and accurate

### **Ollama Setup**
- Install from: https://ollama.ai
- Pull model: `ollama pull llama3.2`
- Private and offline

## 🎯 Pro Tips

1. **Hide Window**: Press `Ctrl + B` when not needed
2. **Multiple Screenshots**: Take multiple for complex problems
3. **Chat First**: Use chat for quick questions
4. **Debug Mode**: Use for fixing errors
5. **Switch Models**: Ollama for privacy, Gemini for speed
6. **Start Fresh**: `Ctrl + R` to clear everything
